# Namespace
## UniverBlazored.{{page.parent}}.{{page.title}}

## Remarks
This namespace has all avaiable scoped services for the Univer's spreadsheet component.

- The listener is used to get data at specific location on the spreadsheet.
- The javascript interop is used for initialize all libraries used in the component, depend of wich is avaiable via configuration
- The Agent is used to get/set all data from/to Univer's UI
